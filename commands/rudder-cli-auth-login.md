## rudder-cli auth login

Login with an access token

### Synopsis

Prompt for a RudderStack access token, verify it, and save it to the selected CLI configuration file for later workspace API requests.

```
rudder-cli auth login [flags]
```

### Examples

```
  rudder-cli auth login
```
