        About this page

        This page shows what your app sent to the local listener. The listener answers like RudderStack, keeps every request in memory, and loses it all when it stops. Nothing here goes to RudderStack.

        Point your app here

        Set the SDK's data plane URL to . Browser SDKs also need the config URL set to the same address; mobile SDKs need the control plane URL. Server SDKs must flush before they exit.

        What you see

        • Tiles and notices describe the whole capture, whatever the filters.
        • Events lists the accepted events exactly as the SDK sent them.
        • Requests lists every request: refused ones with the reason, and control requests such as the SDK loading its settings or a browser preflight check.
        • Events with no write key show the key as (none). Type (none) in the write key filter to find them.
        • New events appear as they arrive. Pause stops the updates.
        • The filters are part of the page address, so you can share a view.

        Keys

        • / moves to the search box. Up and Down move through the list. Esc closes the details.
